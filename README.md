# Simple UNIX Shell

Командный интерпретатор (Shell) на языке Си с поддержкой конвейеров, перенаправления потоков ввода-вывода и цепочек выполнения команд с проверкой кодов возврата.

---

## 📌 Возможности

* **Управление процессами**: создание и выполнение процессов с помощью системных вызовов `fork`, `execvp`, `waitpid`.
* **Конвейеры (Pipes)**: передача данных между процессами через `|` с использованием `pipe()` и `dup2()`.
* **Перенаправление ввода-вывода**:
  * `>` — запись стандартного вывода в файл;
  * `>>` — дозапись в файл;
  * `<` — чтение стандартного ввода из файла.
* **Логика выполнения команд**:
  * `;` — последовательное выполнение;
  * `&&` — выполнение следующей команды только при успешном завершении предыдущей;
  * `||` — выполнение следующей команды только в случае ошибки предыдущей.
